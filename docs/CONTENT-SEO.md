# Content and SEO Requirements

## Metadata

- Use a clear title such as `Shanid Cherukattil | Lead Frontend Developer`.
- Use a concise description that names frontend architecture, performance, React, and Next.js.
- Add a canonical URL once the production domain is known.
- Add Open Graph and Twitter metadata with a real preview image.
- Keep `lang="en"` and define a favicon and theme color.

## Page Structure

- One descriptive H1 in the hero.
- Use H2 headings for About, Experience, Projects, Skills, and Contact.
- Use descriptive link text instead of generic labels such as `click here`.
- Preserve meaningful section IDs for navigation and shared links.

## Portfolio Content

Every project entry should include:

- The product or domain.
- The user's responsibility.
- The technical challenge.
- The solution or architectural decision.
- A measurable outcome when it can be verified.
- Technologies used, without turning the entry into a keyword list.

## Structured Data

Consider JSON-LD for `Person`, `WebSite`, and `CreativeWork` or `SoftwareApplication` project entries after the real profile URLs and project links are confirmed. Do not publish invented organizations, metrics, or URLs.

## Search and Sharing Checklist

- [ ] Production domain is configured.
- [ ] `robots.txt` permits the intended route.
- [ ] Sitemap contains the canonical homepage.
- [ ] Social preview image renders correctly.
- [ ] No placeholder copy remains.
- [ ] All claims and metrics are fact-checked.
- [ ] Resume and external profile links are current.
